# Histórico do projeto

Esta pasta reúne os registros das entregas anteriores. Datas, resultados de testes e decisões descrevem cada entrega; não representam uma nova validação do sistema atual.

- Os documentos numerados de 21 a 37 registram implementações e revisões.
- `planejamento/` guarda os planos, especificações e pesquisas antes agrupados em `docs/superpowers/`.
- `reviews/` contém os relatórios de evidências originais.
- [Índice anterior](indice-anterior.md) conserva o mapa detalhado dos documentos.
- Os documentos de definição do produto, numerados de 01 a 20, estão em [produto](../produto/01-visao-do-produto.md).

As capturas e os registros auxiliares citados como `.impeccable/review/` e `.taste-skill/` estão preservados no [backup anterior à organização](../guias/organizacao-do-projeto.md#recuperação). Os JSONs de evidências mantêm os caminhos originais da época da captura.

Novas capturas geradas pelos scripts ficam em `exports/revisao-visual/publico/` e `exports/revisao-visual/operacao/`, fora da documentação e ignoradas pelo Git.

Volte ao [índice atual](../README.md) para localizar os guias de uso.
