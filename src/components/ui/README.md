# Componentes públicos adaptados

`@/components/ui` resolve para esta pasta, mantendo os componentes React de apresentação separados dos componentes JavaScript operacionais. Os dois modelos fornecidos pelo responsável foram adaptados aqui: preços com Number Flow e seleção animada; gráfico com faixas, foco, leitura acessível e dados industriais ilustrativos. Não transportar os textos Web3/IA nem benefícios inexistentes. Tailwind/TypeScript são compilados pelo Vite; não é necessário migrar a aplicação para Next.js ou executar um scaffold shadcn sobre ela.
