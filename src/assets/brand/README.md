# Identidade visual

Esta pasta receberá os arquivos finais da marca do SIVI.

## Mascote

- mascote definido: **raposa**;
- direção possível: visual semelhante à raposa do Firefox, conforme direito de uso informado pela equipe;
- versão gráfica final ainda precisa ser entregue e aprovada;
- formato preferencial para interface: SVG otimizado; WebP com transparência é a alternativa raster.

Quando o arquivo autorizado estiver disponível, usar um nome claro como `mascote-raposa.svg` e registrar sua origem/licença na documentação do projeto.
